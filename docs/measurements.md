# Лист замеров

Для каждой комнаты: длины всех стен, диагонали, высота потолка; ширина и высота проёмов, расстояния до углов; открывание дверей; высота подоконников; отопительные приборы; точки розеток, выключателей, воды, канализации и вентиляции.

Кухня: отдельно проверить высоту подоконника относительно будущей столешницы и позиции выводов.

Санузел: тип и точное положение установленной сантехники.

Котельная: фото оборудования, паспортные требования доступа.

Фотографии: каждый угол каждой комнаты и общий проход.
