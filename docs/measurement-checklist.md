# Короткий чек-лист для владельцев · обмеры дома

**Перед стартом:** рулетка или лазерный дальномер, лист исходного плана, карандаш, телефон. Все размеры в миллиметрах.

- [ ] Снять видео-проход по дому и назвать номера комнат.
- [ ] В каждой из 7 комнат измерить все стены, 2 диагонали и высоту потолка в нескольких точках.
- [ ] Для каждого окна и двери записать размеры, отступы от углов и способ открывания.
- [ ] Сфотографировать каждую стену прямо, каждый угол, пол и потолок.
- [ ] Отметить розетки, выключатели, свет, радиаторы, вентиляцию, трубы, воду и канализацию.
- [ ] Для кухни показать точную стену гарнитура и все инженерные выводы.
- [ ] Для санузла показать, что уже установлено; где стиральная машина.
- [ ] Для котельной снять оборудование и шильдики/модели (не пересылая личные данные); **ничего самостоятельно не переносить**.
- [ ] Подписать фотографии: «№6-стена-А», «№6-окно-1» и т. п.
- [ ] Все неизвестные показатели оставить пустыми — не угадывать.

Расширенное задание: `docs/measurements.md`. Отсутствие части данных не мешает начать проверку остального, но не позволяет выпускать финальные монтажные размеры.
