# Ксюша и Руслан — кабинет-гостевая №3 · концепция 0.6

**Назначение утверждено:** кабинет + гостевая спальня. Площадь по плану 11,6 м²; высота потолков 2,7 м; перегородки сохраняются. **Статус:** эскиз для согласования, не монтажные чертежи и не обмерная 3D-модель.

## Стиль
Утверждённое направление А: тёплый современный минимализм. Молочный #F2EEE5, светлый дуб #D5B78F, песочный #C9B9A3, оливковый #969F83, немного графита #706C65. Пол единый с жилыми комнатами.

## Функциональные зоны
- **Рабочая:** стол ориентировочно 120×60 см у окна с учётом бликов, удобное кресло, точка света; уточнить питание компьютера.
- **Гостевая:** компактный раскладной диван ориентировочно 160–190 см по ширине, желательное спальное место около 140×200 см. Требуются габариты *разложенного* дивана и проверка проходов.
- **Хранение:** закрытый шкаф/полки глубиной ориентировочно 40–60 см, включая место под бельё и документы. Крепить высокую мебель согласно инструкции.

## Освещение
Общий потолочный свет, локальный направленный для стола и отдельный мягкий вечерний у дивана. Существующие электроточки пока не обследованы.
