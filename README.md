# Proekt Disign

Статический сайт-каталог дизайн-проектов. Первый проект: **Ксюша и Руслан**.

## Публикация на GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
Ожидаемый адрес после включения Pages: https://koraevgog-create.github.io/Proekt-Disign/

## Структура
- `index.html` — каталог проектов.
- `projects/ksyusha-ruslan/index.html` — страница проекта.
- `assets/style.css` — адаптивный дизайн и стили печати.
- `assets/data.js` — помещения и лимиты бюджета.
- `assets/project.js` — интерактивные разделы, расходы, CSV, печать.
- `assets/*.svg` — эскизные планы.
- `assets/source-plan.jpg`, `assets/kitchen-location.jpg` — исходники заказчика.
- `docs/` — задание, лист замеров и CSV бюджета.

Нет сборки, сервера и обязательных JS-зависимостей. Google Fonts — необязательные внешние шрифты, есть системные резервные.
Фактические расходы хранятся только локально в браузере, не синхронизируются между посетителями. CSV позволяет сохранить расходы отдельно.

## Статус 0.1
Эскизная концепция; не рабочий комплект для монтажа. Планы восстановлены по фотографии, проёмы приблизительные. Не проверены фактические проходы и открывание дверей. Площади комнат в сумме 84,9 м², кадастровая площадь 89,1 м².
Бюджет содержит лимиты без актуальных цен и количества товаров. Визуализации и рабочая документация перечислены как будущие этапы, а не готовые материалы.

## Добавить проект
Создать отдельную папку `projects/<slug>/`, отдельные данные и документы, добавить карточку на главной. Не перезаписывать данные существующего проекта.
